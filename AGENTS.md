# AI Agent Best Practices Knowledge Base

A curated knowledge base of AI agent best practices based on primary sources such as official documentation from OpenAI, Anthropic, Google, Microsoft, LangChain, and related providers.

## Quick Reference

- Source of truth: `content/`
- Generated output: `dist/` (do not edit directly)
- Prefer small, targeted `biome lint` and `biome format` runs on changed files
- Use `npm run verify:full` before handing off changes that affect the site shell, article pages, glossary behavior, or tests
