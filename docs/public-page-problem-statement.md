# Public Page Problem Statement

このドキュメントは、`AI Agent Best Practices Knowledge Base` を公開するときに、読者が初見でも目的をすぐ理解できるようにするための問題設定をまとめたものです。

## Problem Statement

AIエージェントを使った開発経験がある読者に向けて、主要な公式ドキュメントを横断整理したナレッジベースを公開したい。

現状のままだと、初見の読者が「何のサイトか」「誰向けか」「何を読めばよいか」「いつ時点の情報か」をすぐ判断しにくい可能性がある。

そのため、公開ページの冒頭で目的・対象読者・読み方・対象時点を明確にし、読者が自分に関係ある情報かどうかをすぐ判断できる状態にする。

## Why now

AIエージェント関連の情報は変化が速く、公式ドキュメントの内容も陳腐化しやすい。

公開時点で、情報の対象時点と位置づけを明示しておかないと、読者が最新情報として誤解したり、自分向けの内容か判断できなかったりする。

## Success Criteria

- 初見の読者が10秒以内に「これはAIエージェント開発経験者向けに、主要な公式ドキュメントを横断整理したものだ」と理解できる
- 初見の読者が30秒以内に、自分が読むべき章を目次から選べる
- 読者が、このナレッジベースの内容がいつ時点の公式ドキュメントをもとにしているかをすぐ確認できる
- 読者が、最新仕様・料金・制限・推奨事項については各公式ドキュメントを確認すべきだと理解できる

## Target Readers

AIエージェントを使った開発経験があり、自己流の使い方から一歩進んで、主要な公式ドキュメントに基づいてエージェント活用を改善したい人向け。

具体的には、次のような人を想定する。

- AIエージェントと一緒にコーディングしている人
- AIエージェントを使ってアプリやツールを作ったことがある人
- エージェントだけに任せて、自分はコーディングしない形で開発したことがある人
- 特定ツールの経験に閉じず、エージェント設計・評価・運用の考え方を横断的に知りたい人
- 自分の開発フローを、主要な公式ドキュメントに基づいて見直したい人

## Reader Benefit

このナレッジベースを読むことで、OpenAI / Anthropic / Google / Microsoft / LangChain などの主要な公式ドキュメントを横断し、エージェントの設計・評価・運用・コーディング活用に共通するベストプラクティスを整理できる。

読み終えることで、自分のエージェント活用を、思いつきや経験則だけでなく、公式ドキュメントに基づいて見直せるようになる。

## Reading Model

このナレッジベースは、最初から順番に読む必要はない。

章ごとにテーマを分けているため、読者はいま知りたい内容や、自分の開発で見直したい領域から読める。

## Non-goals

- AIエージェントをまだ使ったことがない人向けの入門記事にすること
- AIエージェントを使い始めたばかりの人向けのチュートリアルにすること
- AIエージェント関連の最新ニュース集にすること
- 特定ツールの詳しい操作手順や使い方マニュアルにすること

## Constraints

- 主要な公式ドキュメントをもとにする
- 単なるリンク集ではなく、テーマ別に横断整理した内容として見せる
- 章の目次を並べ、読者が読みたい章から読める構成にする
- 情報の対象時点を明記する
- 最新性が必要な仕様・料金・制限・推奨事項は、公式ドキュメント確認を促す

## Recommended opening copy

```md
# AI Agent Best Practices Knowledge Base

AIエージェントを使った開発経験がある人向けに、OpenAI / Anthropic / Google / Microsoft / LangChain などの主要な公式ドキュメントを横断整理したナレッジベースです。

単なるリンク集ではなく、エージェントの設計・評価・運用・コーディング活用に関するベストプラクティスをテーマ別に整理し、自分の開発フローを見直すための観点を提供します。
```
